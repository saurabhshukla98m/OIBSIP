## Project Overview
This project focuses on segmenting customers based on their purchasing behaviour using machine learning techniques.

The objective is to identify different customer groups and understand their purchasing patterns to help businesses develop targeted marketing strategies.

## Dataset
Dataset Name: data.csv

The dataset is used for customer behaviour analysis and clustering.

1. Data Loading and Inspection
2. Data Cleaning and Preprocessing

5. Data Standardization

7. Elbow Method
8. Customer Segmentation Visualization

## Machine Learning Algorithm
K-Means Clustering is used to group customers based on similarities in their characteristics.
